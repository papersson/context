In devenv.nix, you configure this directly through the `nixpkgs.config` option:

```nix
{ pkgs, ... }:

{
  nixpkgs.config.allowUnfree = true;

  services.mongodb.enable = true;
}
```

If you're using devenv with flakes and that doesn't work, you may need to pass it through the flake input. In your `flake.nix`:

```nix
{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    devenv.url = "github:cachix/devenv";
  };

  outputs = { self, nixpkgs, devenv, ... }@inputs:
    let
      pkgs = import nixpkgs {
        system = "x86_64-linux"; # or your system
        config.allowUnfree = true;
      };
    in {
      devShells.x86_64-linux.default = devenv.lib.mkShell {
        inherit inputs pkgs;
        modules = [ ./devenv.nix ];
      };
    };
}
```

The key is passing the `pkgs` with `config.allowUnfree = true` already set to `mkShell`.

If you're using devenv without flakes (just `devenv.nix` + `devenv.yaml`), the first approach should work. If it still doesn't, you can also try the environment variable approach as a workaround:

```bash
NIXPKGS_ALLOW_UNFREE=1 devenv shell
```

Though that's less elegant than having it in the config. Which setup are you using—flakes or the standalone devenv.yaml approach?
