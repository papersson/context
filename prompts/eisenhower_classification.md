**Eisenhower Matrix Task Classifier**

Classify each task from the provided context into the appropriate Eisenhower quadrant.

**Before classifying:**
- If goals or priorities aren't explicit, state your assumptions first
- If a task should be split, renamed, or doesn't belong on the list at all, say so

**Classification Criteria:**

- **Urgent**: Deadline is soon relative to the effort required, blocks others, or has consequences if delayed
- **Important**: Directly advances stated goals, has significant downstream impact, or builds lasting value (e.g., skills, systems, relationships)

**Quadrant Definitions:**

| Quadrant | Label | Action |
|----------|-------|--------|
| Q1 | Urgent + Important | Do immediately |
| Q2 | Not Urgent + Important | Schedule dedicated time |
| Q3 | Urgent + Not Important | Delegate or batch |
| Q4 | Not Urgent + Not Important | Eliminate or defer indefinitely |

**Output format:**

Group tasks by quadrant. For each task:
```
- [task name] — [1 sentence reasoning]
  [optional: flag effort as ⚡low, 🔶medium, or 🔴high if relevant to sequencing]
  [optional: note if it unblocks other work or classification is uncertain]
```

**Then provide an action plan** as a short numbered sequence (5-10 items max) covering what to do today, this week, and what to schedule or drop.
